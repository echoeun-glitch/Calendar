# 체육 연간 시간표

기초(주간) 시간표를 한 번 넣으면 시작일~종료일의 연간 시간표가 만들어지고,
행사·결손·보강을 달력에서 고치면 학급별 차시와 시수가 다시 계산됩니다.

## 쓰는 순서

1. **설정 → 1. 기초 시간표** — 매주 반복되는 시간표를 채웁니다(요일 × 교시 → 학급 + 장소).
2. **설정 → 3. 기간** — 시작일과 종료일을 학사일정에 맞춥니다.
3. **설정 → 4. 행사 · 휴업일** — «공휴일 한 번에 넣기»를 누르고, 방학·재량휴업일·학교 행사를
   직접 추가합니다. **시작일~종료일로 기간을 한 번에** 넣을 수 있고(주말은 자동으로 빠집니다),
   목록에서 날짜·이름·수업 여부를 그 자리에서 고치거나 지울 수 있습니다.
   추석·설날은 음력에서 오는 날짜라 학사일정과 대조해 주세요.
4. **연간** — 전체 기간이 한 장에 들어가는 배열표(주차 × 요일·교시). 가로로 인쇄하면 A4 한 장.
   왼쪽 «기간» 칸을 누르면 그 주의 행사·휴업일을 지정합니다.

## 화면

- **연간** (첫 화면) — 한 장 배열표. 표 아래에 학급별 «오늘까지 한 차시 / 전체 차시»가 나옵니다. 행은 주차와 기간, 열은 요일 × 교시, 칸은 학급(장소 색).
  휴업일은 그 날 전체가 빨간 글씨로 덮이고, 결손은 취소선, 보강은 밑줄로 구분됩니다.
  안 쓰는 교시 열은 접어서 표를 좁게 유지하고, 차시 번호를 함께 켤 수 있습니다.
  칸을 **한 번** 누르면 학급만 그 날짜에 한해 바꾸고(«지우기»로 빈칸), **두 번** 누르면 상세 화면이 열립니다.
- **주간** — 교시 × 요일 격자. 요일 머리글을 누르면 행사·휴업일을 지정합니다.
- **일지** — 하루 단위. 그날 수업 목록(교시·학급·장소·차시)을 띄워 진도와 특이사항을
  바로 적고, 아래 큰 칸에 그날 일지를 씁니다. «지난 일지»에서 이전 날짜로 돌아갑니다.
- **학급별** — 학급별 수업 기록과 시수 집계.

## 특징

- 휴업일·행사일의 수업은 차시에서 빠지고, 뒤 차시가 자동으로 당겨집니다.
- 빈 칸에는 수업을 추가할 수 있고, 같은 시간에 다른 수업이 있거나 장소가 겹치면 경고합니다.
- 총차시는 기본적으로 시간표에서 자동으로 셉니다.
- **학급을 누르면 «전체 차시»와 «수업 기간»을 정합니다.**
  - **전체 차시** — 교육과정 배당 시수. **카드의 숫자 칸에 바로 넣을 수 있습니다**
    (비워 두면 시간표대로 센 수가 흐리게 보입니다). 넣으면 카드가 «오늘까지 / 목표»로 바뀌고,
    편성된 차시가 모자라면 «N차시 모자람»으로 알려줍니다. **칸을 비우지는 않습니다.**
    아래 체크박스를 켰을 때만 그 차시를 넘는 뒤쪽 칸을 쓰지 않습니다.
  - **수업 기간** — 기본값은 설정의 전체 기간입니다. 그대로 저장하면 «전체 기간»으로
    남아 나중에 설정의 기간을 바꾸면 따라옵니다. 한 학기만 하는
  학급에 씁니다. 기간 밖의 칸은 연간 표에서 빗금 친 «쓰지 않는 칸»이 되고, 학급 이름은
  흐리게 남아 있어 사라진 것처럼 보이지 않습니다. 그 칸을 눌러 다른 학급을 넣을 수 있고,
  표 위의 안내에서 한 번에 «전체 기간»으로 되돌릴 수 있습니다.
- 보강을 안 잡은 결손이 있는 학급은 빨갛게 표시됩니다 (그만큼 시수가 모자랍니다).
- 설정 → 5. 데이터에 **앱 버전**이 표시됩니다. 최신 파일을 쓰고 있는지 확인할 때 보세요.
- 수업 기록: 진도·수업 내용, 특이사항.
- 차시는 «그 기간에 화면에 보이는 칸»만 셉니다. 숨은 가산은 없습니다.
- 인쇄, CSV(엑셀) 내보내기 — 수업 기록 / 시수 집계 / 연간 시간표 / 수업 일지.

## 저장

데이터는 **브라우저(localStorage)에만** 저장됩니다. 서버로 나가지 않습니다.
기기를 옮기거나 백업하려면 **설정 → 5. 데이터**에서 백업 파일을 내보내고 불러오세요.
내보낸 파일은 브라우저의 **다운로드 폴더**에 `PE-backup-날짜.json` 으로 저장됩니다.
PC·폰 자동 동기화는 아직 없습니다.

## 설치

`pe/` 폴더를 웹에 올리고(예: GitHub Pages) 주소를 연 뒤,
브라우저 메뉴에서 **홈 화면에 추가**하면 앱처럼 열립니다. 오프라인에서도 동작합니다.
파일을 직접 열어(`file://`) 쓸 수도 있지만, 그때는 설치와 오프라인 캐시가 동작하지 않습니다.

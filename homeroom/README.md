# 학급일지

담임이 하루 단위로 쓰는 학급일지입니다. Google 계정으로 로그인하면 내 계정에 저장되어 PC·휴대폰에서 이어서 쓸 수 있고, 다른 선생님은 내 일지를 볼 수 없습니다. 로그인 방식과 저장·동기화는 [전담일지](../pe/)와 같습니다(같은 Firebase 프로젝트, 별도 저장소 `homeroomJournals/{사용자 ID}`).

## 쓰는 순서

1. **설정 → 1. 학급 정보** — 학년도·학교·학년·반·담임.
2. **설정 → 2. 명렬표** — 학생을 하나씩 추가하거나, 엑셀에서 «번호 이름 성별» 칸을 복사해 붙여넣습니다.
3. **설정 → 3. 기초 시간표** — 요일 × 교시 과목. 일지의 과목 칸에 자동으로 채워집니다.

## 화면

- **일지** — 날짜별로 날씨, 행사·학사일정, 휴업일 표시, **출결**(학생을 눌러 결석·지각·조퇴·결과 × 질병·미인정·기타, 출석인정, 사유 메모), 교시별 과목·학습 내용, 알림장·과제·준비물, 생활지도·학급 특이사항, 메모, 그날의 학생 기록을 씁니다. 인쇄할 수 있습니다.
- **달력** — 한 달을 한눈에. 날짜마다 행사·휴업일, 결석·지각·조퇴·결과 인원, 메모 첫 줄이 보이고 누르면 그날 일지가 열립니다.
- **출결부** — 학생 × 평일 월별 표(질결·미지·기조·인 …). 칸을 눌러 바로 고치고, 이번 달 합계와 학년도 누계, 날짜별 출석 인원이 나옵니다. 인쇄·CSV 내보내기.
- **학생** — 학생별 학년도 출결 집계(사유별), 출결 내역, **누가기록**(학습·생활·교우관계·상담·학부모·건강·칭찬·기타).
- **설정 → 4. 데이터** — 백업 파일 내보내기/불러오기, 학년도 출결 CSV, 누가기록 CSV, 로그인 후 «이 기기의 기존 일지 가져오기».

## 운영자 설정 (한 번만)

1. Firebase 콘솔 → Firestore → **규칙**에 `pe/firestore.rules` 전체를 붙여넣고 게시합니다. `homeroomJournals` 규칙이 추가되어 있어 게시 전에는 로그인 후 저장이 거부됩니다.
2. `homeroom/` 폴더를 GitHub Pages 배포 브랜치에 반영합니다. 주소는 `…/Calendar/homeroom/`입니다. 승인된 도메인은 전담일지와 같아 따로 추가할 필요가 없습니다.

# 학급일지

담임이 하루 단위로 쓰는 학급일지입니다. Google 계정으로 로그인하면 내 계정에 저장되어 PC·휴대폰에서 이어서 쓸 수 있고, 다른 선생님은 내 일지를 볼 수 없습니다. 전담일지와 완전히 분리된 별도 Firebase 프로젝트(`homeroom-journal`)를 사용하며, 데이터는 `homeroomJournals/{사용자 ID}`에 저장됩니다.

## 쓰는 순서

1. **설정** — 학년도·학교·학년·반·담임, 기초 시간표(요일 × 교시 과목).
2. **명렬표** — 학생을 하나씩 추가하거나, 엑셀에서 «번호 이름 성별» 칸을 복사해 붙여넣습니다.

## 메뉴 (PC에서는 왼쪽 탭, 휴대폰에서는 위쪽 탭)

- **출결** — 첫 화면. 날짜를 고르고 학생을 눌러 결석·지각·조퇴·결과 × 질병·미인정·기타, 출석인정과 사유를 입력합니다. 아래에 월별 출결부(이번 달 합계·학년도 누계·출석 인원, 인쇄·CSV)가 있습니다.
- **일지** — 날씨, 행사·학사일정, 휴업일, 그날 출결 요약, 교시별 과목·학습 내용(기초 시간표에서 자동), 알림장·과제·준비물, 생활지도·특이사항, 메모, 그날의 학생 기록. 인쇄할 수 있습니다.
- **명렬표** — 번호·이름·성별·보호자 연락처·비고. 인쇄할 수 있습니다.
- **평가** — 과목·평가 영역·날짜·척도(잘함·보통·노력요함 / 4단계 / 상·중·하 / 점수)·성취기준을 정하고 학생별 결과와 관찰 내용을 적습니다. 분포·평균이 나오고 CSV·인쇄가 됩니다.
- **누가기록** — 전체 또는 학생별. 학생을 고르면 학년도 출결 집계(사유별)와 출결 내역, 관찰·상담 기록(학습·생활·교우관계·상담·학부모·건강·칭찬·기타)이 나옵니다.
- **예산사용** — 예산 총액, 사용액·잔액·사용 비율, 구분별 합계, 사용 내역(날짜·구분·내용·금액·비고). CSV·인쇄.
- **메모** — 자유 메모. 고정, 검색.
- **달력** — 한 달을 한눈에. 날짜마다 행사·휴업일, 결석·지각·조퇴·결과 인원, 메모 첫 줄. 누르면 그날 일지가 열립니다.
- **설정** — 학급 정보, 기초 시간표, 백업 내보내기/불러오기, 출결·누가기록 CSV, 로그인 후 «이 기기의 기존 일지 가져오기».

## 운영자 설정 (한 번만)

1. Firebase 콘솔 → `homeroom-journal` 프로젝트 → Firestore → **규칙**에 `homeroom/firestore.rules` 전체를 붙여넣고 게시합니다. (Google 로그인, Firestore(서울), 승인된 도메인 `echoeun-glitch.github.io` 설정 완료)
2. `homeroom/` 폴더를 GitHub Pages 배포 브랜치에 반영합니다. 주소는 `…/Calendar/homeroom/`입니다.
